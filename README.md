# Castle Fight

Учебный проект: одна линия, покупка зданий, автобой юнитов, 6 фракций.

## Установка (Arch / любой Linux)

```bash
python -m venv ~/.venvs/castle
source ~/.venvs/castle/bin/activate
pip install -r requirements.txt
```

- В `requirements.txt` стоит **pygame-ce** — у него есть готовые сборки и под свежий Python (3.13/3.14 на Arch).
  Обычный `pygame` под Python 3.14 из pip не ставится (нет сборки, просит `sdl-config`).
- Если что-то не встало: `pip install pygame-ce` (а уже установленный `pygame` сначала удалить:
  `pip uninstall pygame` — оба пакета дают модуль `pygame` и мешают друг другу).
- Игра работает и с обычным `pygame` 2.5+ (проверено на pygame 2.6.1 и pygame-ce 2.5.8).
- Системные пакеты не нужны: картинки грузятся через Pillow, шрифты — через встроенный `_freetype`.
- `scipy` нужен только инструменту пересборки спрайтов (`process_assets`), не игре.

Все команды — из корня проекта с активированным venv.

## Запуск

```bash
# тесты
pytest -q

# стычка 5 Мечников vs 5 Лучников
python -m castlefight.tools.skirmish

# бот vs бот (лог по минутам)
python -m castlefight.tools.run_headless Королевство Орда --mode normal --seed 1

# матрица баланса
python -m castlefight.tools.balance_check normal 4

# обучение ML-советника (~2000 матчей)
python -m castlefight.ai.advisor --matches 2000 --eval 40

# pygame UI
python -m castlefight.ui.main
```

### Управление (окно 1280×720)

| Что | Как |
|---|---|
| Меню | `Enter` — играть, `H` — как играть, `Esc` — выход |
| Выбор фракции | клик по карточке или `A/D`, противник `Q/E`, режим `Tab`, `Enter` — в бой |
| Построить здание | клик по карточке внизу или `1–4` → клик по свободной (зелёной) клетке зоны; `Shift`+клик — ставить ещё |
| Переставить | перетащи своё здание мышью в свободную клетку (бесплатно) |
| Продать | **ПКМ** по своему зданию (или навести + `X`) → «пузырь» с ценой → «+N» / `X` / `Enter`; возврат 60% |
| Удар героя | **ЛКМ по вражескому воину** — урон мечом (раз в 0,4 с, у курсора кольцо перезарядки) |
| Лавка | `Q` зелье ярости · `W` каменная кожа · `E` ремонт замка · `R` бомба · `T` меч героя (или клик по предмету) |
| Бомба | `R` → по дороге ездит круг радиуса → клик — сбросить; ПКМ / `Esc` — отмена |
| Армия | `U` — апгрейд (+10% HP и урона всем) |
| Время | `F` или клик по табличке скорости — x1/x2/x4, `Пробел` — пауза, `Esc` — отмена / пауза |
| Подсказки | наведи на карточку, предмет лавки или здание (своё/вражеское) |

Карточка с ленточкой «СОВЕТ» — рекомендация ML-советника.

### Лавка и новые механики (v3)

- **Удар героя** (клик по врагу): урон 14 → 22 → 32 → 44 → 58 по уровням меча, не чаще раза в 0,4 с,
  тип урона «замок» (одинаково по любой броне). Убийство даёт обычную награду.
- **Меч героя** (`T`): 4 уровня, цена 40 / 70 / 110 / 160. Бот меч не качает и не кликает.
- **Зелье ярости** (`Q`, 60 з.): +25% урона всей армии на 30 с, перезарядка 75 с.
- **Каменная кожа** (`W`, 60 з.): армия получает −20% урона 30 с, перезарядка 75 с.
- **Ремонт замка** (`E`, 80 з.): +8% макс. HP замка, перезарядка 90 с, не больше 3 раз за матч.
- **Бомба** (`R`, 170 з. ≈ ульт-здание ×1,2): выбираешь точку на дороге, через 1,2 с падает и наносит
  500 урона всем **вражеским** юнитам в радиусе 100 (≈ 54 px). Перезарядка 100 с. Тень и красный круг
  показывают, куда упадёт; взрыв — вспышка, огонь, дым, ударная волна, тряска экрана.
- **Продажа**: 60% цены здания, клетка освобождается сразу.
- **Свои механики**:
  - *Соседство* — одинаковые здания, стоящие рядом по стороне клетки, выпускают юнитов на 8% чаще
    (зелёный квадратик в углу клетки). Боты ставят здания с учётом этого.
  - *Казна* — каждые 30 с +3% от запаса золота (не больше 6). Награда за то, что не тратишь всё сразу.
  - *Быстрый старт* в обычном режиме: 90 золота на старте и +20/мин (было 60 и +15).
- **Бот и лавка**: ремонтирует замок ниже 45% HP, бросает бомбу в скопление ≥6 врагов у своего замка,
  пьёт зелья только из лишнего золота (когда все места заняты и отложено на апгрейд).

## Структура

- `balance_sim/` — эталонный прототип баланса
- `castlefight/data` — константы и фракции
- `castlefight/core` — логика без pygame
- `castlefight/ai` — боты и советник
- `castlefight/core/shop.py` — лавка (зелья, ремонт, бомба, меч), без pygame
- `castlefight/ui` — pygame: `scenes.py` (экраны), `renderer.py` (поле, юниты, эффекты),
  `hud.py` (верх/низ), `widgets.py` (кнопки-таблички, подсказки), `kit.py` (пиксельные дерево/пергамент/камень),
  `surf.py` (непрозрачный холст кадра), `layout.py` (клетки зон), `assets.py` (спрайты + запасная графика)
- `castlefight/assets` — арт (PNG), фон, иконки лавки, шрифты (OFL: Press Start 2P, Podkova, PT Sans)

## Почему раньше были чёрные прямоугольники

На многих Linux-системах (в т.ч. Arch + pygame-ce) окно получает формат ARGB. Поле рисовалось на
`Surface(...).convert()` — то есть в формате окна, и альфа у фона оставалась 0. Программный блиттер SDL,
когда альфа назначения 0, просто копирует пиксель источника: прозрачные `(0,0,0,0)` края спрайтов
превращались в чёрные прямоугольники, а полупрозрачное затемнение паузы — почти в чёрный экран.
Теперь кадр рисуется на собственном холсте без альфа-канала (`ui/surf.py`) и в конце копируется в окно;
тест `tests/test_render_alpha.py` проверяет это на эмулированном ARGB-окне.
- `castlefight/tools` — headless и проверка баланса

## Баланс v3 (как проверено)

- `balance_check normal 6` (900 матчей): итоговые винрейты фракций 44–58%, матч в среднем 11,8 мин
  (было 13,5), первый ульт ~5,8 мин (было 7,1), таймаутов 0. Турбо: 46–59%, 9,4 мин.
- `balance_v3 normal 8` (по 240 зеркальных матчей): бот с лавкой против бота без неё — 61%;
  «игрок», кликающий на пределе частоты (2,5 удара/с весь матч) с мечом — 66% (турбо 70%);
  кликающий вполовину — 48% (меч окупается только при активной игре). Без меча на пределе — 57%.

## LAN-автопоиск (заготовка)

`castlefight/net/discovery.py`: `Beacon` (хост раз в 1 с шлёт UDP-маячок JSON на порт 47820 —
255.255.255.255, широковещательный адрес подсети и 127.0.0.1) и `Browser` (неблокирующий приём,
живой список игр, «молчащие» дольше 4 с удаляются). Тест — `tests/test_discovery.py` (localhost).
Сетевого матча (TCP-синхронизации) и экрана «Подключиться» в игре пока нет.

## v4

### Игра по локальной сети (2 игрока)
1. Оба компьютера в **одной сети** (один Wi-Fi / роутер).
2. Первый: «По сети» (N) → «Создать игру», выбрать фракцию и режим. На экране — его IP и порт.
3. Второй: «По сети» → «Подключиться». Найденные игры появляются в списке сами (как в Minecraft) — клик по игре.
   Если не нашлась — ввести IP и порт хоста вручную (по умолчанию **47821**) и нажать «Подключиться».
4. **Windows** при первом запуске спросит про брандмауэр — разрешить доступ для **частных сетей**.
   Порты: **UDP 47820** — поиск игр (маяк), **TCP 47821** — сама игра. В «общественных» сетях (кафе, отель) клиенты часто изолированы — не заработает.
5. Хост играет слева (синий), гость справа (красный). Пауза и ускорение в сетевой игре отключены. Если связь пропала — возврат в меню с сообщением.

Устройство: детерминированный lockstep, тики ведёт хост (`castlefight/net/lan.py`). Каждые 0,2 с хост рассылает
список команд обоих игроков; оба компьютера применяют одно и то же и считают одну и ту же симуляцию (общий seed).
Рукопожатие с проверкой версии; контрольная сумма каждые 25 тиков. Тест: `tests/test_lan.py` (хост+клиент по localhost).

### Остальное в v4
- Бот тоже кликает по твоим воинам: ~1–1,5 клика/с со случайными паузами, по тем же правилам (перезарядка 0,4 с), покупает меч.
- Новые пиксельные замки (синий/красный), трещины ниже 50% HP и копоть ниже 25%.
- Городок: каждое построенное здание появляется и на поле рядом со своим замком (переставил/продал — меняется и там).
- «Как играть» — 8 страниц (← → / A D / колёсико), с таблицей урона и брони.
- Исправлено: H в меню не работала с русской раскладкой. Горячие клавиши-буквы теперь по физической клавише; F1 — тоже правила.
- ИИ-советник: вместо kNN — деревья. Точность на отложенных 20% (≈19 тыс. примеров, 1600 матчей):
  kNN 61,0% · дерево 83,8% · RandomForest 90,9% · **HistGradientBoosting 93,5%** (сохранён).
  Переобучить: `python -m castlefight.ai.advisor --matches 1600`.
