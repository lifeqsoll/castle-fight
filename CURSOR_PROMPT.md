## 1. Суть игры
Одна линия (lane), два замка по краям. Игроки не управляют юнитами — они **покупают здания**, здания сами периодически спавнят воинов, воины идут по линии и дерутся. Цель — разрушить вражеский замок.
- 6 фракций (классов): Королевство, Орда, Лес, Некрополь, Аркана, Кузня.
- В каждой фракции 4 здания: **melee** (ближний бой), **ranged** (дальний/маг), **summon** (призыватель, как ведьма в Clash Royale — периодически вызывает миньонов), **ult** (дорогое, долго спавнит, но очень сильный юнит).
- Контрпики через **типы урона и брони**.
- Цель баланса: винрейт каждой фракции ≈ 50% (в прототипе 46.8–53.0% в нормальном режиме).

## 2. Правила и числа (из `stats.py` / `classes.py`)
- Длина линии `LANE = 2000` px, логический шаг `dt = 0.2` c. Замок игрока 0 в x=0, игрока 1 в x=2000; юниты появляются в 30 px от своего замка.
- **Типы урона:** slash, pierce, magic. **Броня:** L (лёгкая), M (средняя), H (тяжёлая), S (рой), R (камень), C (замок). Множители — словарь `MULT[dtype][armor]` в `stats.py`. По замку все типы бьют ×0.25 (у Титана дополнительно `siege=2.0` → ×0.5).
- **Замок:** HP 15000 (normal) / 6000 (turbo), стреляет 200 урона каждые 0.35 с по ближайшему врагу в радиусе 300, 1 цель за выстрел.
- **Слоты:** максимум 12 зданий, из них максимум 2 ult. Здания нельзя разрушить и продать.
- **Экономика (золото в минуту):** `min(cap, base + inc * минута)`.
  - normal: старт 60, base 15, inc 5, cap 55; внезапная смерть с 20-й минуты.
  - turbo: старт 80, base 30, inc 10, cap 70; внезапная смерть с 10-й минуты.
- **Награда за убийство:** `max(1, round(cost*0.02))` (обычные ≈1, ult ≈3), миньоны — 0.
- **Апгрейд** (общий на игрока): +10% к HP и урону новых юнитов за уровень, 5 уровней, цены 100/150/200/250/300.
- **Внезапная смерть:** после минуты SD замки стреляют слабее на 10% в минуту (минимум ×0.2), чтобы игра заканчивалась.
- Первое появление юнита из нового здания — через половину времени спавна (±20%), дальше каждые `spawn` секунд (±5%).
- **Способности** (поля в словаре юнита): `minion/every/maxmin/total` (призыв), `aura_heal` (лечение союзников в радиусе 150), `regen` (самолечение), `cleave`/`splash` (урон по соседям в радиусе 50), `raise_dead` (поднимает убитых врагов как миньонов, до 6), `siege` (множитель по замку).
- **Цели:** юнит атакует самого переднего живого врага, если тот в радиусе; если врагов в радиусе нет, но рядом вражеский замок — бьёт замок; иначе идёт вперёд, но не проходит сквозь передового врага.
- Целевая длительность: normal 15–20 мин, turbo 7–10 мин (прототип: normal ~13.5, turbo ~9.7 — normal можно чуть растянуть позже).

## 3. Архитектура (ООП) — что хочу видеть
```
castlefight/
  data/            # константы и описания (без логики)
    enums.py       # DamageType, ArmorType, Role (Enum)
    balance.py     # таблица урона, экономика, замок — перенос из stats.py
    factions.py    # UnitType/BuildingType/Faction для 6 фракций — перенос из classes.py
  core/            # чистая логика, БЕЗ pygame
    entity.py      # Entity -> Unit, Minion, Castle
    abilities.py   # Ability -> Summon, AuraHeal, Regen, Splash, RaiseDead, Siege
    building.py    # Building (таймер спавна)
    player.py      # Player: золото, здания, апгрейд, покупка
    economy.py     # доход по времени, награды
    world.py       # World: tick(dt), цели, бой, очистка, победа, SD
    game.py        # Game: режим, игроки, цикл, события (для UI и логов)
  ai/
    bots.py        # Bot (ABC) -> RandomBot, MixedBot, CounterBot, RushBot, GreedyBot
    advisor.py     # ML-советник (этап 7)
  tools/
    run_headless.py  # матч бот vs бот в консоли
    balance_check.py # матрица 6x6 как evalb.py
  ui/              # pygame, ТОЛЬКО в конце
    renderer.py, input.py, hud.py
  tests/           # pytest
```
Требования к коду:
- `@dataclass(frozen=True)` для шаблонов (`UnitType`, `BuildingType`, `Faction`), обычные классы для живых объектов.
- Наследование `Entity` → `Unit`/`Castle`; способности — **композиция** (список `Ability` у юнита, у каждой `on_tick`, `on_attack`, `on_kill`), а не if-ы по ключам словаря.
- `core/` вообще не импортирует pygame. UI только читает состояние `World` и вызывает `player.buy(...)`.
- Случайность — через `random.Random(seed)`, передаваемый в `World`, чтобы матчи воспроизводились.
- Type hints, docstring на русском у каждого класса, без глобального состояния.

4. **Player + Economy + Building:** покупка, лимиты слотов/ult, доход, апгрейды, SD, режимы normal/turbo.

7. **ML-советник (`ai/advisor.py`):** прогнать ~2000 матчей ботов, логировать каждую покупку: признаки = (минута, золото, мои здания по ролям 4 числа, здания врага по ролям, доля брони врага L/M/H/S/R, моя фракция, фракция врага one-hot), метка = какую роль купил; оставить только покупки победителей. Обучить `KNeighborsClassifier(n_neighbors=7)` со `StandardScaler` в `Pipeline` и для сравнения `DecisionTreeClassifier(max_depth=6)`; train/val split, вывести accuracy. Сохранить через `joblib`. Метод `advisor.suggest(player, world) -> Role` + бот `MLBot`, который проверяем против `CounterBot` (винрейт).
8. **pygame UI:** окно, линия, замки с HP-барами, юниты кружками/спрайтами цвета команды, панель покупки (4 кнопки + апгрейд), золото, таймер, подсказка советника, меню выбора фракции и режима, бот-оппонент. Рендер ~60 FPS, логика фиксированным шагом 0.2 с (аккумулятор времени).
